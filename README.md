# 分光光度滤光片记录

Windows 图形界面工具，用于通过串口读取分光光度模块返回的 24 路强度数据，完成空气记录或通用滤光片稳定值记录，并生成 Excel 文件。

## 功能概览

- PySide6 图形界面，一页显示 24 个通道。
- 支持波长：410 / 460 / 520 / 550 / 590 / 630 nm。
- 支持通道组：CH1-CH24、CH1-CH12、CH13-CH24。
- 支持空气记录模式和滤光片测试模式。
- 滤光片模式会先暖机并建立空气基底；空气状态下持续维护最近的稳定基底，插入滤光片时冻结当次基底用于计算。
- 原始数据先写入 CSV 缓存，停止后生成原始数据 Excel。
- 插片时按所选通道空气基底的算术平均值冻结通道增益系数，稳定后同时显示原始稳定强度、校准强度和吸光度。
- 滤光片稳定值保存为单独 Excel，同时保存当次空气基底、空气平均值、通道系数、原始稳定强度、校准强度、透过率、吸光度和稳定窗口诊断指标。
- 同一通道多次测量使用样本标准差/CV；一次测量的全部所选通道使用总体标准差/CV。
- 右侧显示运行日志，顶部显示写入行数和稳定通道数量。
- 通道状态点：灰色=未建立基底，绿色=可测试，橙色=检测到滤光片并等待稳定，蓝色=已记录稳定值并等待回到空气。

## 数据采集与处理链路

### 串口数据采集

程序以 `115200, 8N1` 打开串口。开始检测后向设备发送所选波长的启动命令，然后循环读取串口字节流：

1. 每次最多读取 4096 字节并追加到接收缓冲区。
2. 在缓冲区中查找 `5A A5` 帧头，按协议长度提取完整帧。
3. 校验帧功能码、payload 长度和逐字节累加校验和；不完整帧留在缓冲区等待后续字节，校验失败的帧丢弃。
4. payload 前 96 字节按小端格式解析为 24 个 `float`，分别对应 CH1-CH24。
5. 当前协议解析会对每个浮点值取绝对值，得到本帧的24路原始强度。
6. 只有成功解析的完整帧才进入界面显示、空气/滤光片判定和数据保存链路。

滤光片模式的初次暖机和空气基底采集阶段不会写入正式原始数据。全部所选通道建立基底后，程序清空串口输入缓冲和解析缓冲，从下一批有效帧开始逐帧写入 `_temp_csv\串口数据记录.csv`。点击停止后再将CSV转换为原始Excel。因此原始记录不包含初次基底阶段的数据，但包含之后的空气、插片、稳定和拔片过程。

空气记录模式不建立空气基底，也不执行滤光片判稳和校准；每个有效帧直接进入原始记录。

### 数据层级和符号

本文使用以下符号描述单个通道 `i`：

```text
Xi(t)  第t帧收到的原始强度
Bi     该通道最近一次稳定空气基底
B̄      本次所选全部通道空气基底的算术平均值
gi     插片时冻结的通道增益系数
Si     通过滤光片判稳的窗口平均强度
Ci     通道校准后的稳定强度
Ti     当次透过率
Ai     当次吸光度
```

对应关系：

```text
gi = B̄ / Bi
Ci = gi × Si
Ti = Si / Bi
Ai = -log10(Ti)
```

原始强度、空气基底和滤光片稳定强度使用设备返回的同一强度单位；通道系数、透过率和吸光度没有单位。校准强度仍然保持原强度单位。

## 图形界面流程

1. 选择串口、波长、运行模式和通道组。
2. 点击 `开始测试`。
3. 如果是滤光片模式，先保持空气状态；程序按当前配置完成最短暖机（默认30秒），再等待全部所选通道各自的空气窗口（默认20帧）通过判定。
4. 初次基底全部完成后，通道变为绿色。绿色待测期间，各通道继续使用当前配置的空气窗口维护自己的稳定空气基底。
5. 插入滤光片后，当前强度离开空气范围时，程序冻结该通道的空气基底，同时计算所选通道空气基底的算术平均值和通道系数，通道变为橙色。
6. 滤光片在当前配置的完整窗口内（默认10帧）保持插入状态，并满足 CV、斜率和极差条件后，取窗口均值作为原始稳定强度，再乘以冻结的通道系数得到校准强度。
7. 通道卡片依次显示“稳定”“校准”和“吸光度”；原始稳定强度、校准强度、透过率和吸光度同时写入稳定值Excel，通道变为蓝色。
8. 拔出滤光片，回到空气且当前配置的空气窗口（默认20帧）稳定后，更新该通道空气基底并重新变为绿色。
9. 点击 `停止`，程序会关闭串口、生成 Excel，并在日志中输出保存路径。

空气记录模式下不会建立空气基底，也不会生成稳定值 Excel，只持续记录原始数据。

## 稳定值格式

稳定值 Excel 依次包含五个工作表：“稳定强度”“校准强度”“透过率”“吸光度”“测量明细”。各类结果分别保存，不会互相覆盖。

### 稳定强度

保存每个通道的多次滤光片稳定强度：

```text
通道    第1次    第2次    ...    最小值    最大值    平均数    标准差    CV
CH1     数值     数值            数值      数值      数值      数值        数值
CH2     数值                     数值      数值      数值      空白        空白
...
```

同一通道的横向重复测量使用样本标准差和样本 CV；只有一次记录时，标准差和 CV 留空。底部按每一次测试纵向统计当前所选全部通道，使用总体标准差和总体 CV。

同一个通道多次插入滤光片时，新稳定值会横向追加，不会覆盖之前的稳定值。如果选择 12 通道组，稳定值和统计值只覆盖该通道组。

### 校准强度

布局和统计口径与“稳定强度”相同，每一个值均来自同次测量的原始稳定强度和插片时冻结的通道系数：

```text
校准强度 = 原始稳定强度 × 通道系数
通道系数 = 所选通道空气基底算术平均值 / 当次通道空气基底
```

该工作表用于直接比较通道增益均衡前后的强度离散程度。例如可以对比“稳定强度”和“校准强度”底部的总体标准差及总体CV，判断空气增益校准是否减少了通道间差异。

### 透过率

布局与“稳定强度”相同，数值按以下公式计算并以百分比显示：

```text
透过率 = 稳定强度 / 当次空气基底
```

该工作表是比较不同通道滤光片性能的主要统计表，统计口径与“稳定强度”相同。

### 吸光度

位于“透过率”右侧、“测量明细”左侧，布局和统计口径与“稳定强度”相同。每次稳定事件按冻结空气基底得到的透过率计算：

```text
吸光度 Ai = -log10(Ti)
Ti = 稳定强度 Si / 当次空气基底 Bi
```

例如透过率为30%时，计算使用比例 `0.30` 而不是数值 `30`，吸光度约为 `0.522879`。吸光度只用于显示、保存和结果统计，不参与插片识别、空气跟踪或稳定窗口放行。

### 测量明细

每次通道稳定事件保存一行，字段顺序如下：

```text
时间
波长(nm)
通道
次数
空气基底
空气平均值
通道系数
稳定强度
校准强度
透过率
吸光度
窗口帧数
透过率样本标准差
透过率样本CV
透过率极差
透过率斜率/帧
透过率CV阈值
透过率斜率阈值/帧
透过率极差阈值
空气范围容差
判定
```

其中“吸光度”位于“透过率”和“窗口帧数”之间；“测量明细”记录滤光片窗口实际参与放行的 CV、斜率和透过率极差，并保存对应阈值。空气基底使用相同指标口径、不同窗口和阈值执行独立判稳。

“空气平均值”和“通道系数”都是检测到插片时冻结的值，不会在滤光片等待稳定期间继续变化，因此可以完整复算：

```text
测量明细中的校准强度 = 稳定强度 × 通道系数
```

## 通道增益校准

### 校准目的

当前校准针对的是24个采集通道之间的乘性增益差异。真实设备直接返回强度值，即使放入同一片滤光片，不同通道也可能因为光路、探测器灵敏度或模拟增益不同而显示不同强度。软件使用各通道的空气基底将它们统一到同一个空气强度尺度，从而减少通道间强度差异。

这不是滤光片绝对透过率校准。滤光片标注的30%可能存在制造和波长误差，软件不会把测量结果强制修正为30%，也不使用标称透过率参与通道系数计算。

### 算术平均参考值

设本次选择的通道集合为 `G`，其中共有 `m` 个通道。全部通道初次空气判稳完成后，每个通道都有最近的稳定空气基底 `Bi`。在通道 `i` 检测到滤光片的瞬间，软件使用当时保存的全部所选通道空气基底计算算术平均值：

```text
     1
B̄ = ─ × Σ Bj，j ∈ G
     m
```

如果选择 `CH1-CH24`，平均值覆盖24个通道；如果选择12通道组，则只计算该组12个通道。当前算法按已确认方案直接使用算术平均值，不进行中位数替代或异常值自动剔除。

### 系数冻结和校准值

通道 `i` 的增益系数为：

```text
gi = B̄ / Bi
```

空气状态下，各通道的 `Bi` 会持续更新，因此下一次插片计算得到的 `B̄` 和 `gi` 也可能变化。一旦检测到通道 `i` 已插入滤光片，本次使用的 `Bi`、`B̄` 和 `gi` 会同时冻结。滤光片通过稳定判断并得到窗口平均强度 `Si` 后，计算：

```text
Ci = gi × Si
```

界面中的“稳定”显示 `Si`，其下一行“校准”显示 `Ci`。Excel中的“稳定强度”和“校准强度”分别保存这两个值。

### 与透过率的关系

校准强度统一到了公共空气参考 `B̄`。如果再用公共空气参考计算比例：

```text
Ci / B̄ = (B̄ / Bi × Si) / B̄ = Si / Bi = Ti
```

因此空气增益校准不会改变现有透过率，程序继续使用冻结的原始通道空气基底计算：

```text
Ti = Si / Bi
```

吸光度也保持不变：

```text
Ai = -log10(Ti) = -log10(Si / Bi) = -log10(Ci / B̄)
```

“透过率”“吸光度”工作表及滤光片CV、斜率、极差判定均保持原有口径。校准强度和吸光度都不参与插片识别和稳定放行，避免结果计算反向改变状态机行为。

### 能解决和不能解决的问题

该方法适合修正近似线性的通道乘性增益差异，并保留设备原始强度的显示尺度。它不能单独修正：

- 暗电流或零点偏置等加性误差；
- 不同强度区间中的非线性响应；
- 滤光片插入位置、角度和局部不均匀造成的差异；
- 所有通道共同发生的光源整体漂移；
- 滤光片标称透过率与真实透过率之间的绝对误差。

验证校准效果时，应使用同一片滤光片、保持正反面和插入方向一致，完成多轮独立插拔测量；比较“稳定强度”和“校准强度”的总体标准差及总体CV，并使用未参与判断的后续测量确认差异确实持续下降。

## 串口协议

串口参数固定：

```text
115200, 8N1
```

启动采集命令由 `build_cmd(1, 0x50, data)` 生成：

```text
A5 5A 01 50 02 HH LL SUM
```

以 520nm 为例，当前发送：

```text
A5 5A 01 50 02 02 01 55
```

停止命令：

```text
A5 5A 01 50 02 00 00 52
```

波长编号：

```text
410nm -> 0 -> 紫色光
460nm -> 1 -> 蓝色光
520nm -> 2 -> 绿色光
550nm -> 3 -> 绿色光
590nm -> 4 -> 橙色光
630nm -> 5 -> 红色光
```

返回帧解析：

```text
帧头: 5A A5
功能码: 0x56 或 0x57
payload: 至少 96 字节
数据: payload 前 96 字节按小端 24 个 float 解析
SUM: 从帧头开始逐字节累加后取低 8 位
```

软件会丢弃 SUM 校验失败的帧。解析后对每个 float 取绝对值。

## 稳定判定

### 窗口指标计算口径

空气和滤光片使用不同的窗口长度与阈值，但共用同一套归一化指标。设窗口中共有 `n` 帧强度 `x0 ... x(n-1)`，参考空气基底为 `B`，先计算每帧比例：

```text
rk = xk / B
```

窗口比例平均值：

```text
r̄ = Σrk / n
```

透过率样本标准差使用 `n-1` 作为分母：

```text
             Σ(rk - r̄)²
s = sqrt( ───────────── )
                 n - 1
```

样本CV、极差分别为：

```text
CV = s / abs(r̄)
极差 = max(rk) - min(rk)
```

斜率使用窗口帧序号 `k = 0 ... n-1` 对比例 `rk` 做一元最小二乘拟合：

```text
          Σ(k - k̄)(rk - r̄)
斜率 = ───────────────────
              Σ(k - k̄)²
```

该斜率表示每增加一帧，归一化比例平均变化多少。配置文件以“百分点/帧”填写，因此程序运行时会除以100转换为“比例/帧”再比较。CV和极差阈值也从百分比或百分点除以100后参与判断。

所有稳定窗口都是滑动窗口：窗口未满时不判断；窗口满后每收到一帧就移除最早一帧、加入最新一帧并重新判断。只要当前完整窗口同时满足全部条件即可通过，不要求额外再通过第二个独立窗口。同一次插片稳定后会立即进入蓝色等待回空气状态，不会因为后续重叠窗口重复记录第二个值。

### 初次空气基底

滤光片模式启动后先执行最短暖机时间。暖机期间只更新界面实时强度，不向初始基底窗口加入数据。暖机结束后，每个所选通道独立维护自己的空气窗口。

初次尚无历史基底时，程序先用当前完整空气窗口的均值作为临时参考 `B`，再计算上述CV、斜率和极差。窗口通过后，取窗口中全部强度的算术平均值并保留6位小数，作为该通道正式空气基底。全部所选通道都完成初次基底后，测试才进入可插片状态。

### 插片识别

空气基底完成后，程序用以下条件自动识别滤光片插入：

```text
当前值 / 空气基底 < 1 - air_tolerance / 100
```

例如 `air_tolerance = 5` 时，透过率低于 95% 会进入橙色检测状态。调小该值可以检测更接近透明的滤光片，但更容易把空气波动识别为插片。

当前是通用滤光片检测，不再要求透过率落入10%、20%或30%等目标范围。只要强度离开空气范围并满足滤光片窗口稳定条件，就可以记录任意透过率的滤光片。

识别插片的同一时刻会冻结：

```text
该通道空气基底 Bi
所选通道空气平均值 B̄
通道增益系数 gi = B̄ / Bi
```

滤光片等待稳定期间即使其他空气通道更新了基底，本次冻结值也不会改变。

### 滤光片稳定窗口

设滤光片窗口长度 `Nf = filter_stable_window_frames`（当前默认10帧）。插片后最近 `Nf` 帧必须持续低于空气识别下限，并同时满足：

```text
透过率样本 CV <= filter_stable_cv_limit / 100
绝对斜率 <= filter_stable_slope_limit / 100 / 帧
透过率极差 <= filter_stable_range_limit / 100
```

三个阈值的当前默认值分别为 0.25%、0.02 个百分点/帧和 0.25 个百分点。通过后取这 `Nf` 帧均值作为滤光片稳定强度。

稳定事件会同时生成：

```text
原始稳定强度 Si = Nf帧原始强度均值
校准强度 Ci = gi × Si
透过率 Ti = Si / Bi
吸光度 Ai = -log10(Ti)
```

判稳使用的是 `Ti` 对应的窗口比例，而不是校准强度 `Ci` 或吸光度 `Ai`。

### 持续空气跟踪和回空气

空气范围条件：

```text
abs(当前值 / 空气基底 - 1.0) <= air_tolerance / 100
```

例如 `air_tolerance = 5` 时：

```text
95% ~ 105%
```

设空气窗口长度 `Na = air_stable_window_frames`（当前默认20帧）。空气窗口使用最近 `Na` 帧，并同时满足：

```text
透过率样本 CV <= air_stable_cv_limit / 100
绝对斜率 <= air_stable_slope_limit / 100 / 帧
透过率极差 <= air_stable_range_limit / 100
```

程序只要求当前一个完整的 `Na` 帧滑动窗口通过，取这 `Na` 帧均值作为空气基底。初次建立基底前按 `air_warmup_seconds` 完成最短暖机（当前默认30秒）；基底完成后，绿色待测通道会持续维护最近的稳定空气基底。检测到滤光片时，软件停止更新该通道基底并使用冻结值完成本次计算。

稳定值记录后通道变为蓝色。只有当前值重新进入空气范围，并且新的 `Na` 帧空气窗口通过CV、斜率和极差条件，程序才确认滤光片已拔出、更新空气基底并恢复绿色。回空气阶段不会记录第二个滤光片稳定值。空气和滤光片始终使用各自独立的窗口长度及阈值。

## 当前注意事项

- `config.ini` 的 `test_mode` 必须是 `air` 或 `filter`。
- 如果只接一个 12 通道模块，请选择 `CH1-CH12` 或 `CH13-CH24`，否则全通道模式会等待未连接通道。
- 滤光片模式下，空气基底阶段不会写入原始 CSV；基底完成后才开始写入正式原始数据。
- 稳定值 Excel 只有记录到至少一个稳定滤光片值后才会保留。
- 原始CSV、原始Excel和界面主实时数值仍保存/显示设备直接返回的原始强度，不会被校准值覆盖。
- 滤光片稳定值Excel同时保存原始稳定强度、校准强度、透过率和吸光度；吸光度按 `-log10(稳定强度 / 当次空气基底)` 计算。
- 通道增益校准在滤光片模式下自动执行，目前没有单独配置开关，也不进行异常通道自动剔除。
